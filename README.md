📊 Vrinda Store Annual Report 2022 (Excel Dashboard)

Project Description

-> Developed an interactive Sales Analysis Dashboard in Microsoft Excel to monitor and analyse Vrinda Store's annual sales performance for 2022.
-> Utilised Pivot Tables, Pivot Charts, Slicers, and Data Visualisation techniques to transform raw sales data into meaningful business insights.
-> Created dynamic filters for Month, Sales Channel, and Product Category to enable interactive reporting and data exploration.
-> Designed multiple visualisations to track key business metrics, including:
      Orders vs Sales Performance
      Gender-wise Sales Analysis
      Order Status Distribution
      Top Performing States
      Age Group vs Gender Analysis
      Channel-wise Order Distribution
-> Analysed customer purchasing behaviour across different demographics and sales channels.
-> Identified top-performing states and platforms contributing to overall revenue growth.
-> Monitored order fulfilment performance through delivery, cancellation, return, and refund metrics.
-> Built a user-friendly dashboard layout for quick decision-making and business reporting.
-> Applied Excel data analysis techniques to improve data interpretation and reporting efficiency.

📈 Key Insights

Women customers contributed the highest share of sales.
Adults represented the largest customer segment.
Amazon emerged as the leading sales channel.
Maharashtra generated the highest sales revenue.
Most orders were successfully delivered, indicating strong operational performance.
